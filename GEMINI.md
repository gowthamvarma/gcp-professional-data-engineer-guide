# GCP Professional Data Engineer Guide - Gemini Context

This repository is a comprehensive study guide and resource hub for the Google Cloud Professional Data Engineer certification. It is structured as a non-code project, primarily containing documentation, notes, and reference materials.

## Project Overview

The goal of this project is to assist in preparing for the GCP Professional Data Engineer exam. It covers core exam domains including designing, ingesting, processing, storing, analyzing, and maintaining data workloads on Google Cloud Platform.

### Key Technologies Covered
- **Compute & Processing:** Dataflow (Apache Beam), Dataproc (Spark/Hadoop), Pub/Sub.
- **Storage & Databases:** BigQuery, Bigtable, Cloud Storage, Cloud SQL, Cloud Spanner, Firestore.
- **Analysis & ML:** BigQuery ML, Looker, Vertex AI.
- **Operations & Security:** Cloud Monitoring, Cloud Logging, IAM, Encryption.
