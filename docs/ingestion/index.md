# Domain 1: Data Ingestion and Messaging

Welcome to the first stop on our journey! 🚀 Before we can process or analyze data, we have to get it into Google Cloud. This domain focuses on the "In" part of "In/Out".

## What's in this section?
In this domain, we cover how to move data from on-premises environments, other clouds, or SaaS platforms into Google Cloud. We'll also look at how to decouple our systems using messaging.

### Services Covered
- **[Pub/Sub](./pubsub.md):** The backbone of real-time streaming and event-driven architecture.
- **Datastream:** Change Data Capture (CDC) for database replication.
- **Storage Transfer Service:** Moving mountains of data from AWS, Azure, or HTTP locations.
