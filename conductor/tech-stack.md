# Technology Stack - GCP Professional Data Engineer Study Guide

## Documentation & Content
- **Markdown (GFM):** All study materials, summaries, and quizzes are authored in GitHub Flavored Markdown for maximum compatibility and readability.
- **Hierarchical Directory Structure:** Content is organized into `docs/` and `study/` directories for logical separation.

## Research & Data Acquisition
- **Google Search API:** Used for real-time information retrieval on the latest GCP service updates.
- **Chrome DevTools (MCP):** Automated browser automation for extracting deep-dive technical details from official Google Cloud documentation.
- **Local Document Analysis:** Leveraging existing PDFs (Exam Guide, Course Summaries) and local notes as foundational reference material.

## AI & Automation
- **Gemini CLI Agent:** Acts as the primary orchestrator for research, synthesis, and content drafting. The agent manages the research-to-drafting pipeline to ensure comprehensive coverage.
- **Conductor Methodology:** Standardized project management for tracking the development of each guide section.

## Quality Assurance & Validation
- **Markdown Linter:** Ensures consistent formatting and stylistic adherence across all files.
- **Link Checker:** Periodically validates all internal and external links to prevent documentation decay.
- **Exam Guide Alignment Audit:** Systematic cross-referencing of every guide chapter against the official Google Cloud Exam Guide domains.
- **Manual Technical Review:** Final human-in-the-loop validation of complex architectural scenarios and sample question explanations.
