# Track Specification: Build Data Ingestion & Messaging Guide (Exam Domain 1)

## Overview
This track focuses on creating the first section of the GCP Professional Data Engineer Study Guide, covering **Domain 1: Data Ingestion and Messaging**. This includes foundational services required to move data into Google Cloud and decouple systems.

## Scope
- **Pub/Sub:** Messaging and streaming.
- **Datastream:** Change Data Capture (CDC).
- **Storage Transfer Service:** Large-scale data migration.

## Requirements
For each service:
1.  **High-Signal Summary:** A "need-to-know" overview of the service's role in the exam.
2.  **Key Concepts:** Detailed explanations of the topics identified in `services_guide.md` (e.g., Dead Letter Topics, CDC Backfill).
3.  **Visual Callouts:** Use of emojis and bold text for Tips, Warnings, and Fast Facts.
4.  **Sample Questions:**
    - 1x Direct Fact-Check.
    - 1x Situational Analysis.
    - 1x Architectural Design.
5.  **Detailed Explanations:** Full rationale for correct/incorrect answers.
6.  **Deep-Dive Links:** Granular links to official documentation.

## Success Criteria
- Markdown files render correctly on GitHub.
- Content is concise, conversational, and follows the Product Guidelines.
- All technical facts are verified against 2026 exam standards.
